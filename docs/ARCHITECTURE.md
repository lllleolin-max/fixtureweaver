# Architecture and acceptance contract

`weave(source, destination, plan)` publishes one separate database only after every acceptance condition succeeds.

1. Validate the plan/bounds, new destination and quiescent single-file source. Hash source bytes, open a read-only URI, enable/check FK enforcement outside a transaction and begin a source read transaction.
2. Inspect `sqlite_schema`, `table_xinfo`, `table_list`, PK indexes and `foreign_key_list`. Resolve identifiers with SQLite ASCII folding and quote names. Clone the schema in memory to reject unavailable collations/functions. SQLite checks the full source key model and integrity.
3. Select seeds using authorized SELECT predicates. Ordinary rows are located by an unshadowed rowid alias; WITHOUT ROWID rows by their actual PK representation. Those tuples identify resolved rows, **not relationship equality**. Query each non-NULL FK parent as `parent_col = ? AND ...` using bound child values, so parent affinity/collation govern comparisons. A visited queue terminates on cycles and enforces the total retained-row cap.
4. Expand mask columns through FK component edges; reject overlapping classes. For each retained non-NULL occurrence, query each class column as `column = ?` and union matching retained occurrences. This is the transitive equivalence closure of the declared comparison domains. Incompatible domains can collapse identifiers and violate a UNIQUE constraint; output SQLite rejects that candidate with an actionable witness.
5. Generate deterministic HMAC-derived tokens from class name, minimum typed original encoding and supplied salt. INTEGER tokens fit 49 bits; REAL-only groups use exactly representable quarter fractions to prevent NUMERIC affinity from converting them to INTEGER. Actual inserted typeof() values are checked against source storage classes. TEXT/BLOB tokens retain their storage type where column affinity permits; actual SQLite decides acceptance. Mixed BLOB/scalar classes and nonfinite masked identifiers are refused. NULL is untouched. Protection pins the whole group in its original representations, including TEXT `"1.0"`/INTEGER `1` variants.
6. Recreate tables, explicit indexes and views in a sibling temporary DB. Enable/check FKs, begin one transaction and turn on `defer_foreign_keys`. Insert retained rows, preserving independent implicit rowids. This supports immediate/deferred cyclic schemas without relying on table ordering. SQLite enforces CHECK/NOT NULL/UNIQUE at insertion and FKs at commit.
7. Construction uses `INSERT OR ABORT` to override source REPLACE/IGNORE conflict policies during loading; masked collisions must refuse instead of silently dropping rows. After commit, execute FK/integrity checks, verify actual table counts equal retained closure counts, and run exact declared consumer queries. Hash source bytes again and refuse detected changes. Close output, atomically publish with `os.link(temp, destination)`, close source and remove the temporary file. Existing destinations cannot be overwritten.

Validity is for declared relational constraints and queries, not all distributions, aggregation totals, undeclared joins or insert histories. FK closure adds ancestors, not all children. Protection weakens masking. Candidate refusal does not prove every possible mask infeasible; a different salt can fix token collision while incompatible equivalence/uniqueness domains need different declarations.

## Complexity and work bounds

Let R be retained rows, E examined FK edges, M masked occurrences, K columns per class and N source rows scanned. Indexes help SQL lookups. Unindexed closure can cost O(E·N); equality clustering can cost O(M·K·N) plus near-linear union/find. This favors actual engine semantics over a bespoke affinity/collation emulator and can be expensive. Use indexes and bounded test copies.

Memory is O(retained payload + M + schema), bounded by source file/row/cell limits. The `cells` cap is global across classes. Managed source/schema-clone/output connections share a progress handler at interval 1; exceeding `steps` interrupts work. This bounds **observed SQLite progress instructions**, not CPU time or every native internal operation. Setup pragmas, hashing, Python and filesystem IO are outside that instruction counter. `value_bytes` lowers SQLite's string/BLOB/row limit; SQL text is limited to 1 MiB, query results by row count. Limits may reject otherwise valid data.

Validation is intentionally global: even an unselected dangling FK blocks reduction. Autoincrement sequence rows rebuild from retained inserts. SQLite statistics, application/user-version pragmas and storage settings do not copy. Virtual/shadow tables, generated columns, triggers, custom collations/functions and live WAL copies are refused.

The independent oracle is a recursive SQLite set query over 32 seeded small cyclic/self-link/NULL graphs. It calls no private closure helpers, checks exact retained rows and actual FKs, and compares unchanged source bytes. Other tests cover affinity/composite cases, protected representations, uniqueness conflicts, CHECK, partial/expression indexes, views, resource exhaustion and the actual registered console. Release verification builds an ordinary wheel from a named Git archive, installs into an isolated environment, compares source bytes and runs that archive's tests/examples/probes.
